# 社区志愿者服务管理系统-python
### 1、系统功能
志愿服务管理系统，采用前后端分离架构，前端基于Vue3 + Element Plus构建管理界面，后端基于Python FastAPI提供RESTful API服务，数据库使用MySQL通过 SQLAlchemy ORM操作。系统实现了志愿者注册审核、活动发布报名、签到签退时长统计、 RBAC权限管理等核心功能

· 登录

· 注册

· 首页

· 志愿服务：志愿活动 | 我的服务

· 志愿管理：活动管理 | 报名管理 | 志愿者管理

· 系统管理：账号管理 | 角色管理 | 菜单管理
